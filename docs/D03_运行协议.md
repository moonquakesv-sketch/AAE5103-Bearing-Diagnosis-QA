运行协议 v1.1／守卫修订 007；模型及原训练结果仍为修订 006；本轮范围为训练、验证、模型冻结。所有新运行输出写入 `runs/d03/` 的新目录，正式测试须另获用户决定。

输入沿用修订 005 的数据冻结，以 `data/samples.csv` 为唯一窗口入口。16 条 DE 记录；0／1 HP 训练 232 窗、2 HP 验证 236 窗、3 HP 测试 236 窗。来源组及来源族保持原映射；来源族跨集合不等于试件隔离。只读取 `model_image_path` 的 224×224 RGB PNG；不读取复核图作为模型输入，不重新切片、平衡、拟合颜色或调节 CWT。测试只读元数据和文件字节做完整性检查，不解码视觉评价，不提取特征，不预测或评分。

权重明确为 `ResNet18_Weights.IMAGENET1K_V1`，官方 URL 由已安装 torchvision 枚举获取。先查 Torch 缓存；缺失时可下载到本次目录 `weights/`，验证官方文件名 SHA-256 前缀并记录完整哈希。必须严格加载完整 state dict 后才替换 fc 为 Identity，记录加载前后状态摘要；失败即停止，不允许随机权重回退。最终特征为 `avgpool` 全局平均池化后 flatten 的 512 维向量。eval、全部参数 requires_grad=False、inference_mode；没有优化器或微调。

RGB uint8 转 float32 除 255 一次，再减 ImageNet mean、除 std 一次。没有 resize、crop 或增强。[torchvision 官方说明](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.resnet18.html)的默认 transforms 带 256 缩放和 224 中心裁剪，因此这里手工实现输入契约。CPU 是本次明确设备；另记录 MPS 编译及可用状态。种子 5103，4 个 Torch CPU 线程，batch=16；数值复现容差在配置中预先声明。

## 预先声明的选择规则

配置为 `configs/d03.yaml`。仅 8 组：linear／RBF × C={0.01,0.1,1,10}，RBF gamma=scale。其他 SVC 参数明确落盘，probability=False、OVR decision_function、break_ties=False。Scaler 只 fit 232 个训练特征，SVM 只 fit 训练特征和标签；不做随机窗口 CV，不把验证重新并入训练。

主指标 validation macro-F1；并列容差 1e-12 内再选 balanced accuracy，更后优先 linear、较小 C、声明顺序。`declare` 在任何验证评分前保存配置、协议、代码与输入哈希和时间；后续校验绑定。8 个候选都保存训练／验证预测、完整指标和逐记录结果。结果不触发扩大搜索。

类别编号／矩阵顺序固定为 0 normal、1 inner_race、2 outer_race、3 rolling_element。混淆矩阵行是真值、列是预测；recall=TP/(TP+FN)；F1=2TP/(2TP+FP+FN)，零分母记 0；macro-F1 为四类 F1 算术平均，balanced accuracy 为本集合有真值支持类别的 recall 平均。全体训练／验证四类都有支持；单记录报告固定四类矩阵、真实类别 recall、accuracy 和计数，避免把单类记录的四类 macro-F1 当作独立四类性能。窗口是计数单位，不给基于独立试件假设的置信区间。训练分数为拟合诊断，验证分数已用于选择，均不等于测试效果。

输出 `decision_score` 是长度 4 的未校准 OVR 数组，顺序见 classes.json，与 SVC.classes_ 核对。它来自多分类投票／margin 转换，[SVC 文档](https://scikit-learn.org/stable/modules/generated/sklearn.svm.SVC.html)说明其含义；不称为概率。predict 使用 SVC 的 OVO 投票，极端并列下不承诺等于 OVR 分数 argmax；输出预测与分数分别由对应接口取得。
